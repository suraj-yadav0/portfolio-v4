The Evolution of My Portfolios: From HTML Basics to Portfolio v4

A deep retrospective on every personal portfolio iteration I've designed and shipped—how my architecture matured from basic college templates to a zero-framework, hardware-accelerated Linux engineering showcase.

Suraj Yadav Software Engineer · CALIN Global Services India

Table of Contents

1. The Philosophy of an Engineering Portfolio

A software engineer's portfolio is more than an online resume—it is living proof of your taste, attention to detail, and technical standards. In an era where boilerplate AI templates and generic component libraries look identical, building a distinctive personal site is your strongest signal of craftsmanship.

Over my five years of software engineering—from starting Computer Science at Chandigarh Engineering College to writing native QML/C++ applications for Ubuntu Touch at CALIN—my personal portfolio underwent four major generational redesigns. Each version mirrors an exact chapter in my technical growth.

2. Portfolio v1 (2021 – 2022): The Genesis

Version 1.0 · First Year B.Tech CSE

Portfolio v1 was built during my first semester of college when I was discovering the fundamentals of web standards. It was raw, straightforward, and focused on proving that I could build something from scratch.

TECH STACK: PORTFOLIO V1

Pure HTML5, Vanilla CSS3, minimal JS. Zero build tools. Hosted on GitHub Pages.

What Worked Well:

  • No Dependencies: No heavy libraries; the page weighed less than 120KB.
  • Clear Intent: Listed early C++ algorithmic assignments, basic data structures, and linked directly to my fresh GitHub profile.

What Needed Improvement:

  • Static Visuals: No scroll physics, no dynamic telemetry, and standard browser fonts.
  • Lacked Identity: Looked like a standard student website without a clear niche or personal brand.

3. Portfolio v2 (2023): The Interactive Era & DSA Streak

Version 2.0 · Competitive Programming & Flutter

By 2023, I was deep into data structures and algorithms, solving hundreds of problems across LeetCode, HackerRank, and GeeksforGeeks. Portfolio v2 was designed to showcase quantitative problem-solving rigor alongside my early cross-platform Flutter experiments.

TECH STACK: PORTFOLIO V2

CSS Grid & Flexbox architecture, dark/light theme engine via CSS variables, automated LeetCode stat counters.

Key Advancements:

  • Bento Grid Layout: Introduced structured metric cards displaying 500+ solved problems and continuous streak stats.
  • Thematic Consistency: Shifted to a focused dark theme with neon accent lines and monospace data readouts.
  • First Mobile Showcase: Embedded interactive preview mockups of early Flutter applications.

4. Portfolio v3 (2024): The Linux & QML Identity

Version 3.0 · Ubuntu Touch & Lomiri Desktop

2024 marked my definitive shift into native Linux application development. While most engineers focused exclusively on iOS and Android, I began writing native QML, C++, and Python software for Ubuntu Touch and open Linux desktops. Portfolio v3 was engineered around this core thesis: "Native software for platforms others forgot."

TECH STACK: PORTFOLIO V3

Modular ES6 architecture, SVG badges for OpenStore listings, upstream Dekko 2 merge request badges, and NotAtMrp internship metrics.

Milestones Showcased:

  • OpenStore Ecosystem: Direct links to live installs for WhatsWeb, Money Manager UT, and clockApp.
  • Upstream Open Source: Documented 5 merged merge requests to the core Dekko 2 email client.
  • Internship Impact: Quantified a 70% decrease in wait time and 30% speed lift achieved during my Flutter internship at NotAtMrp.

5. Portfolio v4 (2025 – 2026): The Zero-Framework Masterpiece (Current)

Version 4.0 · Current Production Site

Portfolio v4 represents the culmination of everything I've learned about web performance, typography, inertial physics, and engineering aesthetic. Built with zero framework overhead, it combines terminal precision with high-end agency polish.

portfolio-v4-spec.json 
{
  "runtime": "Vanilla ES6+ (Zero Build Step)",
  "accent": "#E95420 (Ubuntu Orange)",
  "typography": ["Space Grotesk", "JetBrains Mono"],
  "scrollPhysics": "Lenis 1.1 + GSAP 3 ScrollTrigger",
  "radius": 0, // Strict rule: radius 0 everywhere
  "liveTelemetry": ["GitHub API", "LeetCode API", "53-Week HeatMap"],
  "lighthouseScore": 100
}

Core Architecture Innovations in v4:

  1. Flagship Sticky Card Stack: Multi-layer card deck where each of the 5 flagship projects (Quantro, utgpt, Time Management, WishGift, clockApp) pins to the top of the viewport with hardware-accelerated depth scaling.
  2. Universal Word-by-Word Scroll Illumination: Text starts dimmed at opacity: 0.16 and progressively illuminates into sharp white as the reader's eyes move down the page, acting as an ambient visual reading guide.
  3. Real-Time 53-Week GitHub HeatMap: An interactive SVG calendar engine rendering 371 daily contribution squares with instant hover tooltips, daily commit counts, all-time totals (4,506+), and multi-year filter tabs.
  4. 9 Verified GitHub Achievement Trophies: Custom inline vector badges matching high-tier ranks (Rainbow S, Gold SSS, Rose AAA) with specular pointer lighting.
  5. Live API Telemetry & Quick-Copy: Asynchronous live synchronization with GitHub and LeetCode endpoints with graceful static fallbacks and zero layout shift.

7. 5 Key Takeaways for Developers Building Portfolios

01

Do Not Use Generic Templates

Recruiters and engineers can identify generic frameworks in 3 seconds. Custom typography, strict layout constraints (like our radius-0 rule), and calibrated accents make your work unforgettable.

02

Performance is a Feature

A portfolio with a 5MB JavaScript bundle defeats its own purpose. Zero-framework HTML/CSS/JS loads instantaneously and provides 60FPS animations on any device.

03

Highlight Your Niche

Instead of claiming to do everything, double down on what makes you unique—for me, that was building native software for Linux phones and open desktops.

04

Proof Over Promises

Don't just write "proficient in Python". Show 1,100+ solved DSA problems, 112 public repositories, 5 merged Dekko 2 MRs, and verified GitHub trophies.

05

Iterate Constantly

Your portfolio is never finished. Revisit it every year to prune outdated projects, refine typography, and reflect your current technical ceiling.
